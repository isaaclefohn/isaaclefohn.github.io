# Expo-ready CHROMA icon set

Generated by `brand-drafts/generate_expo_ready.py` from
the Concept E (Detonation Bead) source. **NOT yet wired
into the production build** — see brand-design-spec.md
for the icon-direction decision rationale.

To deploy once you commit to Concept E:

```bash
cp brand-drafts/expo-ready/icon.png          assets/icon.png
cp brand-drafts/expo-ready/adaptive-icon.png assets/adaptive-icon.png
cp brand-drafts/expo-ready/splash-icon.png   assets/splash-icon.png
cp brand-drafts/expo-ready/favicon.png       assets/favicon.png
```

Then in `app.json` confirm:
- `expo.icon` points at `./assets/icon.png` (default already)
- `expo.android.adaptiveIcon.backgroundColor` is `#0F0E1A`
- `expo.splash.backgroundColor` is `#0F0E1A`
- `expo.web.favicon` points at `./assets/favicon.png`

These all already match expectations — the only step is
the `cp` quartet above.
